# Self-hosted web fonts

These Latin WOFF2 files replace `next/font/google` so production builds do not
contact Google Fonts. They are the same font subsets previously emitted by the
Next.js font loader.

| `dm-mono-latin-400.woff2` | [Google Fonts: DM Mono](https://github.com/google/fonts/tree/main/ofl/dmmono) | `fd7521f3531a5ccfc655b25c4f22e9871df3ec141ad79bb27fde20d0df347b6d` |
